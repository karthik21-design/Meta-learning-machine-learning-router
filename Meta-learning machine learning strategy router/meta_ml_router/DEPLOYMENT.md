# Deploying the Prototype for a Live Demo (Streamlit Community Cloud)

This gets you a public URL like `https://your-app-name.streamlit.app` that you
can open on any screen during the Round 2 review — no laptop setup needed on
the reviewer's side.

## 1. Push the project to GitHub

```bash
cd meta_ml_router
git init
git add .
git commit -m "Meta-Learning ML Strategy Router"
```

Create a new **public** repository on GitHub (e.g. `meta-ml-router`), then:

```bash
git remote add origin https://github.com/<your-username>/meta-ml-router.git
git branch -M main
git push -u origin main
```

> If you don't already use git/GitHub, the easiest path is: go to
> github.com → "New repository" → drag-and-drop upload the whole
> `meta_ml_router` folder in the web UI instead of using the terminal.

## 2. Deploy on Streamlit Community Cloud

1. Go to **share.streamlit.io** and sign in with your GitHub account.
2. Click **"New app"**.
3. Select your `meta-ml-router` repository, branch `main`.
4. Set **Main file path** to `app.py`.
5. Click **Deploy**.

Streamlit Cloud automatically reads `requirements.txt` and installs
everything (`streamlit`, `scikit-learn`, `pandas`, etc.) — no extra config
needed.

## 3. Before your review

The trained models (`models/*.pkl`) and benchmark data (`data/meta_dataset.csv`)
are generated by `demo.py`, not committed as raw pickles by default in some
setups. To be safe, **run `python demo.py` once locally before pushing**, so
the `models/` and `data/` folders (with the trained `.pkl` files and CSVs)
are included in your GitHub push and deployed as-is. This avoids the app
retraining on every cold start.

## 4. During the demo

- Open your `*.streamlit.app` link on the projector/screen.
- Use the built-in sample datasets (Iris / Diabetes) for a guaranteed-working
  demo, or upload a CSV live if a reviewer wants to test their own data.
- Walk through: upload → target column → "Recommend algorithm" → point out
  the confidence score, ranked candidates, and the plain-English explanation
  — this is the "smart routing function" the case study asked for.

## Troubleshooting

| Issue | Fix |
|---|---|
| App crashes on startup with a missing-file error | Make sure `models/*.pkl` and `data/meta_dataset.csv` were committed — re-run `python demo.py` and `git add -A && git commit` |
| "Module not found" error on deploy | Check `requirements.txt` was pushed and matches the imports in `app.py` / `src/` |
| App sleeps after inactivity | Free-tier Streamlit apps sleep after a period of no traffic — just reopen the link a minute before your slot, it wakes up automatically |
